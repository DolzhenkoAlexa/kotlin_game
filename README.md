# Репозиторий для разработки собственной игры на Kotlin

## Выбранная игра: Битва Героев

### О проекте:
Это приложение для проведения игр и администрирования партий. Она позволяет записывать ходы игроков, а система проверяет их корректность по правилам, сохраняет историю и считает статистику.
Игра является выдуманной, все правила подробнее расписаны в rules.md

Сам проект будет выполнен на kotlin, а сохранение историй партий и статистики игроков будет исполнено при помощи sql.
