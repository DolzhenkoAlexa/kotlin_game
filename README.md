# Репозиторий для разработки собственной игры на Kotlin

## Выбранная игра: Морской бой

### О проекте:
Это приложение для администрирования партий. Она позволяет записывать ходы игроков, а система проверяет их корректность по правилам, сохраняет историю и считает статистику.
Сам Морской Бой немного изменен, кроме классических правил, будут добавлены еще 3 режима (с минами, с ограниченным колвом боезарядов, с возможностью двигать корабли). 
Все правила подробнее расписаны в rules.md

Сам проект будет выполнен на kotlin, а сохранение историй партий и статистики игроков будет исполнено при помощи sql.
