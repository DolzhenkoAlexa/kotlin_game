# Игра Битва героев

## Цель
Победить всех героев противника

## Герои и ход игры
У каждого героя: **HP**, **Атака**, **Защита**.
Урон считается по формуле "Атака − Защита цели" (минимум 1, чтобы была защита от бесконечной партии)
Игроки не могут выбирать одинаковых героев

Игроки ходят по очереди, за свой ход они могут атаковать или защититься
Кроме этого в режиме с маной есть возможность кидать кубик и копить ману, чтобы применять более сильные атаки

## Режимы

### 1. Классический режим
- У каждого **1 герой**, героев требуется выбрать разных
- Есть только "атаковать" и "защититься"

### 2. Режим с маной
- У каждого **1 герой**, героев требуется выбрать разных
- Вместо атаки можно **бросить кубик (0–6)** — выпавшее число добавляется в пул маны (максимум - 10).
- Из действий есть "атаковать", "защититься", "бросить кубик" (тратит ход), а также "применить сверхспособность" (тратит 10 маны)
- Сверхспособность уникальна для каждого героя

### 3. Режим с отрядом
- У каждого игрока **3 героя**, выбор происходит по очереди без повторений героев
- За ход нужно выбрать одного живого героя → действие → атаковать героя противника.
- Побеждает тот, у кого остался хотя бы один живой герой
- В этом режиме также есть сверхспособности, но без маны, у каждого героя способность можно применить лишь раз
