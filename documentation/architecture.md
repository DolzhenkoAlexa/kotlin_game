# Архитектура проекта «Морской бой»
Приложение построено вокруг четырёх ключевых компонентов: управляющий модуль GameEngine, интерфейсный модуль Console, модуль работы с базой данных DatabaseManager и модуль правил.
Так же есть набор классов, связанных с самой игрой (Game, Player, GameHistory, Moves, Board и тд).

## Управляющий модуль GameEngine
GameEngine — это главный класс, который управляет работой всех остальных классов. 
Именно через него проходят все действия пользователя, так как он связан со всеми классами игры.
Все действия происходят именно через него, например, placeShip() - расстановка кораблей, работает так: проверяет через GameRules.isValidPlacement() валидность расстановки и обновляет Board.

## Интерфейсный модуль Console
Console — это класс для общения с пользователем.
Важно подчеркнуть, что Console не содержит игровой логики. Она только показывает меню, выдает команды, получает ввод и передаёт управление в GameEngine. 
Консоль берет от GameEngine только то, что выставлено публично, а к внутреннему управлению всей игрой и администрированию у консоли доступа нет.  

## База данных DatabaseManager
DatabaseManager отвечает за сохранение и загрузку всех партий. 
Благодаря ему рейтинги игроков и история партий не теряются при выключении программы. Этот компонент работает с SQL.

## Правила (GameRules и наследники)
Правила вынесены в отдельную иерархию классов, чтобы новые игровые режимы можно было добавлять без переписывания GameEngine. 
GameEngine хранит ссылку на текущий currentRules, а все проверки происходят при помощи GameRules и класса с выбранным режимом.

Абстрактный класс GameRules
Задаёт общий каркас для всех режимов, который в основном не нужно переписывать. 
Именно этот класс отвечает за базовые проверки, например, isValidBounds (проверка не выходят ли координаты за границы поля), isNotRepeated (не было ли выстрела в эту клетку ранее), isValidPlacement (корректно ли расставлены корабли). 
Остальной функционал уже прописывается в классах, которые являются наследниками GameRules.

Классический режим: ClassicModeRules
Базовый режим без дополнительных механик. 
processShot() проверяет попадание/промах, при попадании (applyDamage()) даёт дополнительный ход, при уничтожении последнего корабля завершает игру.

Режим с минами: BombModeRules:
Кроме того, что он также как и все остальные наследники использует proccessShot() и applyDamage(), от также использует applyBombDamage().

Режим Огранниченных Снарядов: LimitedModeRules
У данного режима есть отдельные особенности в реализации.  апример, processShot(), сначала проверяет наличие снарядов, затем вызывает findTarget() с учётом площади поражения (некоторые снаряды поражают больше одной клетки). 
Также переопределяет метод setWinner(), так как в этом режиме есть ничья, если у обоих игроков снарядов на нуле. 

Режим двигающихся кораблей: MovingModeRules 
В этом режиме у игрока есть выбор: выстрелить или переместить свой корабль, для этого в нем есть отдельные методы, например, canMoveShip() и validateMove()


## Сущности для самой игры
Эти классы описывают, какие данные существуют в системе и как они связаны. 
Они не содержат логики игры, в основном в них именно наполнение самой игры. Все остальные важные компоненты (GameEngine, DatabaseManager и тд) работают с этими классами.

Game (партия)
Хранит данные об одной сыгранной партии

Player (игрок)
Хранит данные об игроке, который участвует в партии, его айди, его рейтинг, а также его корабли и мины.

GameHistory (история ходов)
Класс, который собирает все ходы текущей партии при помощи List<Moves> 
После завершения партии список ходов из GameHistory передается в DatabaseManager

Moves (ходы)
Хранит информацию о ходах, записанных в историю (то есть только валидных действиях). 
Здесь хранятся только координаты, вид действия и результат.

Board (игровое поле)
Представляет поле одного участника (размер 10 на 10), состоит из Array[10][10] из Cell.

Каждая клетка (Cell) содержит кординаты и тип содержимого 
(так как для пустой клетки символ - точка, для корабля - ■, для мины - #, для попадания - X), то есть дает символьное отображение (для Console.viewBoard())

Coordinates (координаты)
Просто хранит важные координаты (кораблей и мин)
